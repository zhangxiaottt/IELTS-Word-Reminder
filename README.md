# 雅思单词悬浮记忆工具 (IELTS Word Reminder)

一款常驻系统托盘的雅思单词记忆悬浮工具：悬浮面板自动轮播单词，支持一键录入、
认识/不认识标记、词库管理与导入导出，帮助利用碎片时间高效背单词。

- 技术栈：Python 3.10 + PySide6 + SQLite
- 词典数据：有道免费词典 API（在线查询音标 / 释义 / 例句）

## 目录结构

```
IELTS-Word-Reminder/
├── main.py                    # 程序入口（托盘 / 快捷键 / 启动悬浮面板）
├── requirements.txt           # 依赖清单（稳定版本）
├── config/                    # 配置文件 config.json（自动生成）
├── data/                      # 单词库 word_lib.db（自动生成）
├── assets/                    # 图标等资源（icon.png 自动生成，可自行替换）
├── src/                       # 功能模块
│   ├── config.py              #   ConfigManager 配置管理
│   ├── dict_api.py            #   DictAPI 有道词典 API（单例）
│   ├── word_manager.py        #   WordManager 单词数据管理
│   ├── float_panel.py         #   FloatPanel 复习悬浮面板
│   ├── input_widget.py        #   InputWidget 单词录入窗口
│   ├── settings_window.py     #   SettingsWindow 设置窗口
│   ├── word_library_window.py #   WordLibraryWindow 单词库管理窗口
│   └── utils.py               #   路径 / 开机自启 / 任务栏隐藏等工具
└── tests/                     # 自动化测试（冒烟 + 功能）
```

## 安装与运行

```bash
# 1. 安装依赖（建议 Python 3.10）
pip install -r requirements.txt

# 2. 启动程序
python main.py
```

程序启动后最小化到系统托盘（无任务栏图标），悬浮复习面板出现在屏幕左上角附近。

### 桌面小宠（Q版双马尾少女）

设置窗口可开启/关闭「显示桌宠」：
- 小宠尺寸约为面板高度的 3 倍（高分辨率自适应），默认站在“悬浮面板正下方”（贴住下缘、水平居中），随面板拖动/缩放自动跟随
- 支持拖拽：把小人拖到屏幕任意位置，松开后就在该处附近活动
- 右键菜单可「回到面板内」或「隐藏小宠」
- 简单动画：上下浮动 + 左右游走 + 轻微“呼吸”（脚底固定、身体微微收放） + 定时“眨眼”（多帧）
- 点击小宠会跳跷反应，并在头顶弹出“带小尾巴的圆角气泡”说出当前单词的词义（如：apple：n. 苹果）；词库为空时显示随机鼓励语
- 小宠窗口按角色像素生成掩码，透明处可穿透点击到面板，不会挡住按钮

### 面板背景图

设置窗口中可以替浮挂面板设置静态背景图：
- 内置预设：自带 3 张可爱人物风格背景，点击缩略图即可顿时切换
- 自选图片：点「选择图片…」选择本地图片（自动复制到项目内保证不失效）
- 清除：点「清除背景」恢复默认白色
- 背景图会自动采用罩招与半透明白覆盖，保证单词文字始终可读；画面调整大小时图片自动填满

### 录入单词

`Ctrl+Alt+W` 唤起录入框后输入英文单词，自动联网查询音标、释义、例句并实时显示；
按 **回车** 保存（成功后提示「已保存」，1 秒自动关闭）；按 **Esc** 取消。
「中文释义」输入框始终可编辑：自动查到的释义会自动填入，你可以直接修改或完全手动输入自己的释义；网络异常时同样可手动填写。
已录入的单词也可以在「单词库管理」里点「编辑」修改音标/释义/例句。

### 测试模式

与复习浮挂面板相互独立的功能：从词库随机抽词，自动生成选择题检测是否认识该单词。

- 入口：面板「测试」按钮、面板右键「测试模式」、托盘右键「测试模式」
- 题目：展示英文单词 + 音标，选项为其中文释义，3~4 个选项
- 干扰项：自动挑选与目标词释义最相似、不易辨别的其它单词释义
- 答题：即时判分、红绿高亮正确答案、自动进入下一题；一轮 10 题，结束后显示正确率，可再来一轮
- 测试期间自动暂停复习轮播，关闭后恢复

### 复习算法

复习列表严格按优先级生成：
**昨日新词 → 近 5 天录入 → 历史随机**，每组内生词（熟悉度低）优先。

### 设置

轮播间隔 7-20 秒、面板透明度 0.5-1.0 均实时生效；支持设置开机自启。
