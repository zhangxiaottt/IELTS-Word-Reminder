# 雅思单词悬浮记忆工具 (IELTS Word Reminder)

一款常驻系统托盘的雅思单词记忆悬浮工具：悬浮面板自动轮播单词，支持一键录入、
认识/不认识标记、词库管理与导入导出，帮助利用碎片时间高效背单词。

- 界面层：Python 3.10 + PySide6 + SQLite
- 服务层：Java 11（后端承载配置 / 词库 / 复习算法 / 词典 / AI 文章）
- 桥接：Python 界面通过本地 HTTP（127.0.0.1:21001）调用 Java 服务
- 词典数据：有道免费词典 API（在线查询音标 / 释义 / 例句）

## 混合架构说明

本项目采用「哪个语言效果好就用哪个」的混合架构：

```
┌─────────────────────────────── Python 界面层 ───────────────────────────────┐
│  main.py 托盘/快捷键 · FloatPanel 悬浮面板 · DesktopPet 桌宠                 │
│  InputWidget 录入 · SettingsWindow 设置 · WordLibraryWindow 词库             │
│  TestModeWindow 测试 · ReviewArticleWindow 每日文章                         │
└───────────────────────────────┬─────────────────────────────────────────────┘
                                │  src/api_client.py（HTTP 桥接）
                                ▼
┌─────────────────────────────── Java 服务层（java-server） ──────────────────┐
│  ConfigManager 配置 · WordManager 词库/复习算法 · DictAPI 有道词典            │
│  LLMClient 大模型 · ArticleGenerator 每日文章 · LocalServer REST(21001)      │
└──────────────────────────────────────────────────────────────────────────────┘
                config/config.json 与 data/word_lib.db 双端共享（SQLite WAL）
```

- 桌宠动画、悬浮面板等重度依赖 Qt 的界面留在 Python（效果最好）
- 配置、数据库、复习算法、词典请求、大模型请求等后端逻辑移到 Java 服务层
- `main.py` 启动时自动拉起 Java 服务子进程并做健康检查；Java 不可用时
  Python 端自动回退到本地实现（纯 Python 模式），程序不会崩溃

## 安装与运行

```bash
# 1. 安装 Python 依赖（建议 Python 3.10）
pip install -r requirements.txt

# 2. 构建 Java 服务层（需要 JDK 11+；已构建可跳过）
cd java-server && build.bat && cd ..

# 3. 启动程序（会自动拉起 Java 服务；Java 不可用则纯 Python 模式）
python main.py
```

程序启动后最小化到系统托盘（无任务栏图标），悬浮复习面板出现在屏幕左上角附近。

也可单独调试 Java 服务：

```bash
java-server\run.bat            # 启动服务（端口 21001）
curl http://127.0.0.1:21001/api/health   # 健康检查
java-server\test.bat           # 运行全部 JUnit 测试（33 例）
```

### 桌面小宠（Q版双马尾少女）

设置窗口可开启/关闭「显示桌宠」：
- 小宠尺寸约为面板高度的 3 倍（高分辨率自适应），默认站在“悬浮面板正下方”（贴住下缘、水平居中），随面板拖动/缩放自动跟随
- 支持拖拽：把小人拖到屏幕任意位置，松开后就在该处附近活动
- 右键菜单可「回到面板内」或「隐藏小宠」
- 多动作状态机（参考 GitHub 主流桌宠的通用手法，单一贴图 + 程序化动画）：
  - 待机：呼吸收放 + 上下浮动 + 定时眨眼 + 偶尔伸个懒腰
  - 行走：多帧迈步循环（同一少女 3 帧不同跨步姿势轮播）+ 按移动方向水平翻转朝向，能看出真在迈腿
  - 跳跃：抛物线腾空，带「起跳挤压 → 空中拉伸 → 落地挤压回弹」的 squash & stretch
  - 拖拽：拖住悬空，松手后在落点附近活动
- 立体感：脚下有随跳跃高度缩小变淡的「地面软阴影」；光标靠近时她会微微朝光标方向侧身（反应性视线）
- 说话：自动定时（约 25~40 秒）在头顶弹出泛粉色圆角气泡（带小尾巴、像气球轻轻飘动），内容为「日常话语」——按时段问好（早安/午安/晚上好/夜深）与催促背单词等；点击小宠也会跳跃并随口说一句
- 小宠窗口按角色像素生成掩码，透明处可穿透点击到面板，不会挡住按钮

### 房子样式面板（粉色小屋）

面板默认绘制成一间「粉色小屋」样式，与桌宠（Q版双马尾少女）同一色系：
- 粉色花边屋顶（带爱心徽标与烟囱爱心）→ 大窗户（单词显示在里面）→ 底部草地与小花
- 屋顶高度、窗户大小随面板尺寸自适应，文字始终显示在窗户里
- 可在「设置」中关闭房子样式，回到普通白底 / 自选背景图样式（关闭后背景图功能照常可用）

### 面板背景图

设置窗口中可以替浮挂面板设置静态背景图：
- 内置预设：自带 3 张可爱人物风格背景，点击缩略图即可顿时切换
- 自选图片：点「选择图片…」选择本地图片（自动复制到项目内保证不失效）
- 清除：点「清除背景」恢复默认白色
- 背景图会自动采用罩招与半透明白覆盖，保证单词文字始终可读；画面调整大小时图片自动填满

### 录入单词

`Ctrl+Alt+W` 唤起录入框后输入英文单词，自动联网查询音标、释义、例句并实时显示；
按 **回车** 保存（成功后提示「已保存」，1 秒自动关闭）；按 **Esc** 取消。
「中文释义」输入框始终可编辑：自动查到的释义会自动填入，你可以直接修改或完全手动输入自己的释义；网络异常时同样可手动填写。
已录入的单词也可以在「单词库管理」里点「编辑」修改音标/释义/例句。

### 测试模式

与复习浮挂面板相互独立的功能：从词库随机抽词，自动生成选择题检测是否认识该单词。

- 入口：面板「测试」按钮、面板右键「测试模式」、托盘右键「测试模式」
- 题目：展示英文单词 + 音标，选项为其中文释义，3~4 个选项
- 干扰项：自动挑选与目标词释义最相似、不易辨别的其它单词释义
- 答题：即时判分、红绿高亮正确答案、自动进入下一题；一轮 10 题，结束后显示正确率，可再来一轮
- 测试期间自动暂停复习轮播，关闭后恢复

### 每日复习文章

把近几天学过的单词编进一篇连贯的英文短文，在独立窗口中集中展示：
- 入口：托盘右键「每日复习文章」、面板右键「每日复习文章」
- 取词：默认从近 3 天录入的单词中随机取最多 12 个，按词性（名词/动词/形容词/副词）匹配到故事模板槽位，保证语法正确
- 每天的文章按日期归档（data/articles.json）：当天第一次打开自动生成，后续打开保持不变
- 「换一篇」用新随机种子重生并覆盖当天文章；日期导航可回看以前每一天
- 文中近期单词蓝色高亮，右侧词汇表（单词+音标+释义）点击可跳回正文对应位置
- 「复制全文」一键复制纯文本到剪贴板

#### AI 生成文章（可选，大模型写作风更自然）

默认使用本地模板生成；在「设置 → AI 生成文章」里填入一家大模型即可改为 AI 写文章：

| 厂商 | 接口地址（base_url） | 模型名 | 备注 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` | 便宜、英文质量好，推荐 |
| 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seed-2-1-turbo`（或方舟控制台的接入点 ID） | 新客每模型 50 万 tokens 免费 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-turbo` | 新客 100 万 tokens（90 天） |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.7-flash` | 永久免费（有并发限制） |

- 设置窗口已内置上述厂商预设，选中自动填好地址和模型名，只填 API Key 即可
- 「测试连接」按钮可先验证 Key 是否可用
- 所有厂商都是 OpenAI 兼容接口，一套代码、换三个字段（base_url / model / api_key）即切换
- **未配置 Key / 网络失败时自动回落本地模板**，离线也能正常出文章
- API Key 仅保存在本地 `config/config.json`，不会上传

### 复习算法

复习列表严格按优先级生成：
**昨日新词 → 近 5 天录入 → 历史随机**，每组内生词（熟悉度低）优先。

### 设置

轮播间隔 7-20 秒、面板透明度 0.5-1.0 均实时生效；支持设置开机自启。
